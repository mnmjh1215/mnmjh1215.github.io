# mnmjh1215.github.io

Personal academic website of **Jihwan Moon**, served at <https://mnmjh1215.github.io>.

A single static page (no build step) inspired by [Jon Barron's website](https://github.com/jonbarron/jonbarron_website).

## Structure

- `index.html` — the whole site (header, research interests, publications)
- `stylesheet.css` — styling
- `images/profile.png` — header photo
- `images/publications/` — publication thumbnails
- `files/MyCV.pdf` — CV
- `.nojekyll` — tells GitHub Pages to serve the files as-is (no Jekyll)

## Editing

Add a publication by copying an existing `<tr>...</tr>` block in `index.html` and updating the thumbnail, title, authors, venue, links, and description.
